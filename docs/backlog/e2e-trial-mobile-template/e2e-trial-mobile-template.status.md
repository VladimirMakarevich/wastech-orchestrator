The three before it were the ones this campaign never owned, and taking each turned up something its own entry had wrong. F27's lever was outside the repository (the host's `codex` install), its `~33%` was a one-way transition rather than a rate, and this repository's own supported-version floor named the broken release. F7 — the trial's last `major` — pointed at `full-tool-access` step 4, and that is the one lever it must not have: `npm run build`'s body lives in an agent-writable `package.json`, so the key would buy agent-authored execution outside the sandbox. Its whole recorded cost came instead from two role prompts still telling an edit node to run the build and confirm it passes, while `review.md` had already been fixed to say the opposite. What remains is below and is not repairable by code: one named investigation, three verification gaps that need a human or a throwaway repo, and the halves deliberately left inside findings that are otherwise fixed.
