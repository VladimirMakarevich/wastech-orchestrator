## Decided

- **Q1 — Idle-cleanup cadence & budget.** ✅ Decided 2026-06-29 — opportunistic + work-gated (NFR6). Provisional defaults (`MemoryConfig`, tunable): `min_interval = 300s`, `max_scanned = 200`/pass, `max_edits = 50`/pass, `max_wall_clock = 5s`, `promotions_per_pass = 0`. Tune on first live runs.
- **Q2 — Codebase-reconciliation / staleness.** ✅ Decided 2026-06-29 — source of truth = the live repo via `DerivedIndex` (path/symbol existence: `git ls-files` + stat + symbol grep). An entity/lesson whose referenced path/symbol no longer exists → attempt a rename-remap (same basename/content signature); no remap → mark stale → **quarantine, not silent delete**. Deterministic existence = high-confidence auto; anything needing judgment → quarantine (fail-closed). Deeper semantic contradiction is deferred: a lesson auto-drops only on existence failure or a 2× explicit contradiction/supersede signal — never on LLM judgment.
- **Q3 — Promotion thresholds.** ✅ Decided 2026-06-29 — promote to long-term when trust ∈ {repo-observed, human-curated, review-verified, validated artifact-backed} **and** (recurrence ≥ 2 tasks within 60 days **or** trust ∈ {human-curated, review-verified} **or** it explained/prevented a recurring failure **or** it annotates a stable hotspot) **and** no current contradiction. The "stable signal" = the trust level itself (human-curated / review-verified), not a separate flag. `2` / `60d` are `MemoryConfig` defaults, tunable.
- **Q4 — CLI surface & scheduling.** ✅ Decided 2026-06-28 — verbs `worc memory show | validate | compact | restore` (no `defrag` alias; hand-editing the plain files + a possible V1.x `add/edit` cover authoring). Scheduling: built-in bounded idle-gap `CleanupJob`; external cron over the CLI is operator-optional, not built. See [requirements.md](requirements.md) FR6.
- **Q5 — Packet caps & `memory_path` name.** ✅ Decided 2026-06-29 — variable name = **`memory_path`** (final). Default per-node caps (`MemoryConfig`, tunable): baseline ≤ 3 long-term / ≤ 5 entity / ≤ 3 episodic, ~120-line / ~15-bullet backstop; the `implementation` node weighted toward more entity cards, `review` toward more reviewer lessons. Over cap → drop whole lowest-ranked records (NFR4).
- **Q6 — Audit home.** ✅ Decided 2026-06-29 — **both**: a primary append-only, hash-chained `audit/log.jsonl`, plus a best-effort `evaluations` marker row in the orchestrator's existing decision trail. Exact `evaluations` row shape = phase-02 impl detail. See [requirements.md](requirements.md) FR8.
- **Q7 — Episodic detail home.** ✅ Decided 2026-06-29 — resume/debug-grade detail stays in the **existing per-task artifacts** (`logs/<task-id>/`: plan, review, checks, node logs) and `state.db` (`node_lineage`); short-term episodic memory stores only a **distilled episode + pointers** (`artifact_paths`) to them. Memory never duplicates the raw detail (keeps short-term a distillation layer, not a transcript store).
- **Q8 — First-slice ordering.** ✅ Decided 2026-06-28 — all three tiers ship in V1, **staged**: long-term lessons end-to-end first, then short-term episodic, then entity cards (entity last to isolate staleness / `DerivedIndex` risk). See [requirements.md](requirements.md) FR2.
- **Q9 — Candidate-delta contract.** ✅ Decided 2026-06-29 — on **success only**, the supervisor emits a structured `candidate_memory_delta` via structured output on its existing finalize turn: `{ lessons: [{kind, subject, statement, rationale, scope{paths,symbols,nodes}, evidence[], trust_hint}], failures: [{signature, paths, remedy?, evidence[]}], entities: [{entity_id, type, paths, symbols, summary, relationships[], risk_notes[]}] }`. `trust_hint` is **advisory** — `MemoryService` assigns the final trust deterministically (no self-certification to high trust). Best-effort: an absent / malformed / schema-invalid delta → skip + log, finalize/publish never blocked. Exact field names = phase-02 impl detail. See [design.md](design.md) §10.
- **Q10 — Disabled-state guarantees & default.** ✅ Decided 2026-06-29 — disabled (`memory.enabled = false`) ⇒ no `.worc/memory/` created, no `candidate_memory_delta` requested (finalize unchanged), `memory_path` renders empty (existing allowlist `None`→`""`) so a prompt referencing it is unaffected, `worc memory` commands no-op with a "memory disabled" notice, no `CleanupJob`. **Default:** an absent `memory` block (older/upgraded config) loads as **disabled** (no silent behavior change on upgrade — honors FR7); `worc install` on a fresh project writes `enabled: true` by default (operator may decline). Greenfield ⇒ no deployed configs to protect. _(Judgment call — flagged for veto.)_
